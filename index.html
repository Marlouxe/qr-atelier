Comment fonctionne un QR code ?

Commence par comprendre ce que tu regardes : un QR code est une grille organisée. Puis teste tes connaissances avec le puzzle.

1. Une grille de « modules »

Chaque petit carré s'appelle un module. Noir = 1, blanc = 0. Le plus petit QR code (version 1) mesure 21 × 21 modules ; chaque version suivante ajoute 4 modules de côté.

2. Les zones d'un QR code

Repères de position
Les 3 grands carrés dans les coins permettent au scanner de repérer le QR et son orientation, même s'il est tourné.

Lignes de synchronisation
Elles alternent noir/blanc et servent de règle pour compter les modules, même lorsque l'image est déformée.

Informations de format
Elles indiquent notamment le niveau de correction d'erreur et le masque utilisé pour construire la grille.

Données + correction d'erreur
Les données sont accompagnées d'informations de correction qui permettent au scanner de récupérer une partie des modules abîmés.

3. De ton texte à la grille

  1. Encodage : le texte est transformé en données selon un format QR.
  2. Correction d'erreur : des informations supplémentaires permettent de retrouver des données manquantes.
  3. Placement : les bits sont placés dans la grille selon des règles précises, en évitant les zones réservées.
  4. Masquage : le générateur choisit parmi plusieurs motifs pour éviter les formes difficiles à lire.
  5. Zone de silence : une marge blanche autour du QR aide le scanner à détecter ses bords.

Scanner ou pas : quelques repères

Mieux vaut s'abstenir

Prudence dès qu'on vous met la pression, qu'on vous demande de payer, de saisir un mot de passe, un code reçu par SMS ou un numéro de carte, ou lorsque le gain paraît trop beau. Même prudence avec un colis inattendu ou un QR collé dans l'espace public.

Plutôt raisonnable

Un QR peut simplement servir de raccourci vers un menu, un programme ou le Wi-Fi d'un lieu. Dans tous les cas, lisez l'adresse affichée avant d'ouvrir le lien ; pour l'argent ou un compte, préférez l'application ou le site officiel.
