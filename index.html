📱 Atelier : saurez-vous repérer le QR code piégé ?

⚠️ Attention

Cette activité utilise votre téléphone. Rien de dangereux : toutes les pages sont fabriquées pour l'atelier, et aucune donnée n'est collectée.

La consigne

  1. Récupérez les 6 flyers disposés dans la salle.
  2. Scannez chaque QR code avec l'appareil photo de votre téléphone.
  3. Avant d'ouvrir le lien, observez le flyer et l'adresse affichée, puis notez : ✅ sûr ou ❌ douteux.
  4. Ouvrez ensuite le lien : la page vous dit si vous aviez raison.
  5. Sur chaque page, cherchez ce qui aurait pu vous alerter.

Les flyers

Touchez un flyer pour l'agrandir, utilisez les flèches pour passer de l'un à l'autre.
