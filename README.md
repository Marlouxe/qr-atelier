# QR Atelier — site fusionné

Site statique réunissant les deux projets :
- en haut : explications sur le fonctionnement d'un QR code + puzzle à remettre en ordre et à tourner ;
- en dessous : les 6 flyers et leur carrousel ;
- en bas : les repères pour décider avec prudence avant de scanner.

Aucun serveur Python n'est nécessaire : ouvre `index.html` dans un navigateur ou dépose tout le dossier sur un hébergement statique.

Le puzzle utilise la même URL pédagogique que le projet d'origine et le bouton « Nouveau puzzle » mélange à nouveau les 9 tuiles.
